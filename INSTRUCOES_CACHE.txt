═══════════════════════════════════════════════════════════════════
✅ SOLUÇÃO RÁPIDA (ESCOLHA UMA):
═══════════════════════════════════════════════════════════════════

1️⃣ HARD REFRESH (MAIS RÁPIDO - RECOMENDADO):
   
   Windows/Linux:
   → Ctrl + Shift + R
   → OU Ctrl + F5
   
   Mac:
   → Cmd + Shift + R
   → OU Cmd + Option + R

───────────────────────────────────────────────────────────────────

2️⃣ LIMPAR CACHE PELO DEVTOOLS:
   
   1. Pressione F12 (abre DevTools)
   2. Com DevTools aberto, clique direito no botão Reload/Atualizar
   3. Selecione: "Esvaziar cache e atualizar forçadamente"
   
───────────────────────────────────────────────────────────────────

3️⃣ MODO ANÔNIMO/PRIVADO:
   
   Chrome: Ctrl + Shift + N
   Firefox: Ctrl + Shift + P
   Edge: Ctrl + Shift + N
   
   → Acesse o site na janela anônima

───────────────────────────────────────────────────────────────────

4️⃣ LIMPAR CACHE MANUALMENTE:
   
   Chrome/Edge/Brave:
   1. Ctrl + Shift + Delete
   2. Marque "Imagens e arquivos em cache"
   3. Clique em "Limpar dados"
   
   Firefox:
   1. Ctrl + Shift + Delete
   2. Marque "Cache"
   3. Clique em "Limpar agora"
